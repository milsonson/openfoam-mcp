# 测试报告目录规范

本目录用于持续归档 `openfoam-mcp` 的测试报告，支持后续重复新增。

## 命名规范

- 文件名格式：`YYYY-MM-DD-<topic>.md`
- 示例：`2026-02-23-openfoam-remote-call-test.md`
- 同一天多次测试可追加后缀：`YYYY-MM-DD-<topic>-v2.md`

## 报告必含结构

每份报告至少包含以下一级标题：

1. `测试目标`
2. `测试环境`
3. `测试范围`
4. `执行记录`
5. `结果汇总`
6. `问题与风险`
7. `结论`
8. `后续建议`

## 报告清单

- `2026-02-23-openfoam-remote-call-test.md`：`openfoam-remote` MCP 全量接口调用测试
